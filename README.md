# Mochi's Moonlit Labyrinth

A mobile-friendly browser game about an animated cat chasing a clever moon mouse
through a procedurally generated isometric maze.

## Play

Open `index.html` from a local web server. Use WASD or the arrow keys to move,
Shift or Space for zoomies, and F to reveal the mouse's scent trail. Touch
controls are included for mobile devices.

The game uses the Canvas, WebGL, and Web Audio browser APIs with no external
dependencies or build step.
